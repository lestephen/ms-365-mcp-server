# Agent guidance for the EKI fork of ms-365-mcp-server

This is EnviroKinetics' tracking fork of `Softeria/ms-365-mcp-server`. `main` is the EKI
deployment branch: upstream merged in, plus a carried set of EKI changes. Releases are tags
`v<upstream base>-eki.<n>` on `main`, pinned by the `EnviroKinetics/ms365-mcp` harness.
Upstream is merged with merge commits (never rebased or squashed) so upstream history
stays an ancestor.

## Working rules

- Keep the carry small and upstream-shaped. Generic fixes should also be offered upstream;
  EKI-only policy stays here.
- When merging upstream, adopt upstream's version of anything it now does as well as or
  better than the carry, and say so in the PR.
- Checks before pushing: `npm run generate`, `npx tsc --noEmit -p .`, `npx vitest run`,
  `npx prettier --check src test`, `npm run lint` (0 errors).
- When present, `contracts/consumer/` is generated by `test/consumer-contract.test.ts` and consumed by
  EKI helpers and hooks. A diff there is a consumer-facing change: check the consumers in
  `EnviroKinetics/eki` before merging, and regenerate with `UPDATE_CONTRACTS=1` rather than
  hand-editing.

## Review calibration

One internal deployment, users signed in with Entra, behind a Pomerium broker. In a PR that
merges upstream, review the EKI resolutions and the carry, not upstream's own code.

Must never regress (treat a weakening as a blocker):
- The `--blocked-tools` policy on every path: registration, `execute-tool` discovery,
  `graph-batch` subrequests, and OAuth scope grants. No model-callable send without a
  human action.
- The inline file-bytes guard (no base64 file bytes in tool arguments), with only its
  narrow reviewed exception.
- Binary target canonicalization and bounded inline downloads.
- Path-parameter encoding (`src/lib/unencoded-path-params.ts`).
- The consumer contract and the Prometheus metrics on their dedicated listener.

Fine to defer or accept as-is:
- Style and naming in code that upstream owns.
- Speculative hardening that needs a compromised host or tenant admin.
- Refactors of working carry without a concrete defect.

Proportionality: prefer a documented residual or a follow-up issue over growing a PR.
"Real" is not the bar; "worth fixing now" is.
